# tic-tac-toe

Мини-игры на чистом HTML/CSS/JS — без сборки, каждый файл открывается напрямую в браузере.

- `index.html` — **Крестики-персики**: крестики-нолики на двоих или против компьютера.
- `bubbles.html` — **Лопни персик по счёту**: детская игра на счёт 1–5, 1–10 и обратный счёт 10–1.
  Пузыри плавают по полю, лопать их нужно по порядку. Проиграть нельзя: при ошибке персик
  просто мотает головой и подсказывает нужное число. Есть звук (кнопка 🔊) и рекорд раунда
  для каждого уровня.
